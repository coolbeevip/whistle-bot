# Whistle Bot 手机控制台风格指南

界面统一使用英文短标签。底部导航固定为 **Drive**、**Recordings**、**Settings**。顶栏保持单行，左侧显示页面标题，右侧显示底盘连接状态。

## 布局与控件

- **Drive** 的摄像头按实际帧比例显示。四角分别放相机状态、录像计时、预览分辨率和录制按钮。短横屏将预览与操作区左右排列。
- **Joystick** 将档位与驾驶模式放在摇杆下方。**Precision** 和 **Auto** 复用同一预览，执行按钮与档位行底边对齐，运行时原位切换为 **Stop**。
- **Settings** 按功能分组，标签和控件同行，单位跟随数值。**Recordings** 将选择、播放和下载入口放在对应记录行内。
- 页面底色为 `#15191A`，控件底色为 `#202627`，主文字为 `#EDF1EB`。选中和键盘焦点使用琥珀色 `#F4C47B`；在线与录像状态同时使用文字和颜色。
- 按钮触控高度至少 44 px，设置行至少 48 px。使用系统无衬线字体回退；计时和速度使用等宽数字。选择按钮使用 `aria-pressed`，当前导航使用 `aria-current`。

## 组件之间的视觉间距

同一操作组内，处于同一层级的相邻组件应有一致的可见间距。以屏幕上前一个面板或按钮的下边缘到下一个组件上边缘的距离为准。布局时把容器内边距、子元素外边距、网格间隙和空状态行一起计入；同一段留白由一处样式控制。

- **Drive 使用 8 CSS px 作为操作组件间距。** Precision 依次检查「方向选择行 → 数值调节面板 → GO / Stop → 底部导航顶边」，三段均为 8 px。Joystick 的档位行与 Auto 的 GO / Stop 也距同一导航顶边 8 px。底部手势安全区放在导航内部。
- **按层级比较。** Settings 中各分组的标题到面板应彼此一致，Recordings 中各记录行的上下内边距应彼此一致。分组之间可以留出更多空间，分段按钮内部可以更紧凑。较高屏幕上的剩余空间留在操作组外，维持组内控件之间的距离。
- **用实际页面验收。** 在小屏竖屏、常规竖屏和横屏截屏检查，同时测量渲染后组件的边界。切换模式、GO / Stop 和状态提示后复测；同一基准上的间距差应小于 1 CSS px。
