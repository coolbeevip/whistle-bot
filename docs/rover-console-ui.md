# Whistle Bot 手机控制台风格指南

本指南适用于树莓派上位机的手机网页。驾驶者一边看画面，一边用拇指操纵小车，因此摄像头、档位和摇杆应当各有固定位置。新增功能时，行驶中需要立即操作的控件放在 Drive，出发前调整的参数放在 Settings，录完之后的操作放在 Recordings。页面上的文字统一使用英文。[当前页面实现](../upper/camera-preview/index.html)

## 驾驶页布局

| 区域 | 竖屏排列与内容 |
| --- | --- |
| 顶栏 | 左侧为单行标题 `Whistle Bot`，右侧为圆点和底盘状态，如 `Drive online`。连接状态变化时保持顶栏高度。 |
| 摄像头 | 深色圆角取景框，等比完整显示画面。左上显示 `Live` 等相机状态，右上显示 `Standby` 或 `REC · 0:12`，左下显示实际预览分辨率，右下为 `Record` 或 `Stop recording`。画面中心留给路况。 |
| 操控方式 | 在取景框下方切换 `Joystick`、`Precision` 与 `Auto`。Precision 复用摇杆区。点选 `Move` 或 `Turn`、方向与预设值，数值两侧的 ‹ / › 每次调整 0.01 m 或 1°，外侧的 « / » 每次调整 0.10 m 或 10°。长按连续调整，松手停止。两种动作分别保留方向和数值，启动后 `GO` 原位变为 `Stop`；切回 Joystick 释放当前动作。 |
| Auto | 复用预览，在操作区输入原始任务，显示当前步骤与 GO / Stop。切换手动模式时先停止 Auto，停车确认后开放控制。 |
| 档位和模式 | 在 Joystick 页位于摇杆下方、底部导航上方，五个按钮排成一行。前四个等宽，上行显示 `G1` 至 `G4`，下行显示该档目标速度，如 `0.40 m/s`。末项稍宽，上行显示 `Comfort` 或 `Sport`，下行固定为 `Mode`。 |
| 摇杆 | 占据剩余空间，圆形底盘居中，四向箭头围绕可拖动的手柄。底部预留短提示的位置，占用和超时提示出现时，保持摇杆中心与触控范围稳定。 |
| 底栏 | `Drive`、`Recordings`、`Settings` 等宽排列，每项使用线描图标和短标签；当前页用琥珀色标出。 |

手机横屏且视口高度不超过 550 px 时，取景框居左，档位栏和摇杆居右。主内容最大宽度为 800 px，页面使用动态视口高度并为刘海和底部手势区留白。

## 色彩、字体与尺寸

| 用途 | 当前取值 | 使用方式 |
| --- | --- | --- |
| 页面、控件、分隔线 | `#15191A`、`#202627`、`#364041` | 用深色底和 1 px 细线组织内容。摇杆使用轻微渐变和阴影，帮助辨认可拖动的手柄。 |
| 正文、次要文字 | `#EDF1EB`、`#A6B1AD` | 档位名、动作名用主色；单位、辅助标签和未选中导航用次色。 |
| 强调色 | `#F4C47B` | 用于选中档位的文字、当前方向、当前导航和键盘焦点。 |
| 在线、录像 | 底盘在线 `#92DDA8`，直播 `#96E3AF`，录制按钮标记 `#FF766B` | 圆点配文字表达状态。开始录制后，按钮里的红圆点变为方块，文字切到停止动作。 |

字体首选 Barlow，回退到系统无衬线字体。正文 16 px，页标题 21 px，分组标题 17 px，状态与导航 12–13 px。档位值作为第二行辅助信息使用 10 px。计时和设置行的速度读数使用等宽数字，避免更新时跳动。

常规按钮圆角 10 px，取景框 14 px，画面浮层 7 px。按钮触控高度至少 44 px，设置行至少 48 px。浮层使用半透明深底和浅色文字，使明暗场景中的读数都清楚。

## 组件之间的视觉间距

同一操作组内，处于同一层级的相邻组件应有一致的可见间距。以屏幕上前一个面板或按钮的下边缘到下一个组件上边缘的距离为准。布局时把容器内边距、子元素外边距、网格间隙和空状态行一起计入；同一段留白由一处样式控制。

- **Drive 使用 8 CSS px 作为操作组件间距。** Precision 依次检查「方向选择行 → 数值调节面板 → GO / Stop → 底部导航顶边」，三段均为 8 px。Joystick 的档位行与 Auto 的 GO / Stop 也距同一导航顶边 8 px。底部手势安全区放在导航内部。
- **按层级比较。** Settings 中各分组的标题到面板应彼此一致，Recordings 中各记录行的上下内边距应彼此一致。分组之间可以留出更多空间，分段按钮内部可以更紧凑。较高屏幕上的剩余空间留在操作组外，维持组内控件之间的距离。
- **用实际页面验收。** 在小屏竖屏、常规竖屏和横屏截屏检查，同时测量渲染后组件的边界。切换模式、GO / Stop 和状态提示后复测；同一基准上的间距差应小于 1 CSS px。

## 控件行为与文案

- **档位与模式。** 默认四档依次为 0.20、0.40、0.60、0.80 m/s。用户在 Settings 调整某档后，Drive 同步显示该档的新值。Comfort 平顺提速，Sport 更快提速。换档或切换模式后，已按住的方向保持原指令，下一次方向输入采用新设置。
- **摇杆。** 拖动时手柄跟随手指，当前方向箭头与手柄边框亮起。松手、触控取消、离开驾驶页或窗口失焦时回中并释放方向。键盘方向键提供同样的按下与释放反馈。
- **状态。** 顶栏显示底盘连接，相机连接和录像状态分别显示在取景框的两个上角。这样即使底盘离线，仍能看出摄像头是否在工作。提示用 `Drive in use`、`Reconnecting…` 等短语；录制期间底盘离线时用 `Inputs logged` 说明输入仍在记录。
- **可访问性。** 当前导航使用 `aria-current`，档位与模式按钮使用 `aria-pressed`。不可用控件降低亮度并禁用相应操作；键盘焦点使用 2 px 琥珀色外框。给滑块提供包含单位的可读值。

## 设置与录像列表

**Settings** 每个短标题下使用一块深色圆角面板，组内各行以细线分隔。标签靠左并保持单行，选择框或数值靠右。`Resolution` 下分别放 `Preview` 与 `Recording`；`Chassis` 下每档独占一行，依次放 `Gear 1` 等标签、滑块和固定宽度的速度读数。常规调整直接保存；选用高分辨率时，简短说明对预览或录像的影响，由用户决定。

**Recordings** 使用与设置页相同的圆角面板，每行显示选择框、上下排列的日期和 UTC 时间、`Play` 和 `MP4`、`JSON` 下载入口。窄屏允许操作换行。批量删除显示选中数量，确认时明确会一并删除配对文件。列表为空时只显示 `No recordings yet`。

## 改版验收

- 在 320 px 宽的竖屏上检查五个驾驶按钮、单位和模式名能否同排显示，摇杆底部是否位于导航栏上方。
- 横屏检查画面、档位和摇杆是否同时可见。分别切换离线、重连、录像与保存状态，观察摇杆和录像按钮的位置是否稳定。
- 将 G2 改为 0.35 m/s，回到 Drive 检查 G2 的副标签，再切换 Sport，确认用户可以同时读出所选档位和驾驶模式。
