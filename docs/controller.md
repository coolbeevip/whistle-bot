# 控制器构建与调试

正式固件位于 [firmware/controller](../firmware/controller)。在该目录使用 PlatformIO Core。先通过设备列表识别 ESP32 的 UART 下载口，再用实际端口替换示例中的占位符。

```sh
pio run
pio device list
pio run -t upload --upload-port <ESP32串口>
pio device monitor -p <ESP32串口> -b 115200
```

烧录会替换 ESP32 当前程序。下载端口是 ESP32 自身标有 UART 的 USB 口。打开串口监视器后按一次 RESET，启动消息 `wifi_setup` 给出本机热点名称和密码。手机连上该热点后打开 `http://192.168.4.1/`，进入板载控制面板。网页随固件一起烧录，可以离线使用。

## 驾驶和标定

**家庭 Wi-Fi 与指示灯**　手机先连小车热点，在 `http://192.168.4.1/` 打开 **Settings → Wi-Fi settings**。输入或扫描选择 2.4 GHz 的网络名称，填入密码并点 **Test & save**。ESP32 取得局域网地址后才保存凭据。手机连到同一家庭网络后，可通过页面显示的地址进入控制台。网络设置可通过小车热点或 USB 更改。正常启动会重连已保存的网络，失联时开启热点；连上家庭网络满一分钟且没有热点客户端或驾驶会话时关闭热点。

开机运行期间长按 **BOOT** 5 秒，复位键保持松开。按住时板载 RGB 灯闪紫色，触发后先停车，再进入热点模式，保留网络凭据和标定。蓝色常亮表示热点就绪，琥珀色闪烁表示扫描或连接中，绿色常亮表示家庭 Wi-Fi 已连接，红色短暂闪烁表示连接测试或保存失败。要删除家庭网络，在热点设置页点 **Forget network**。

1. 先架空车轮，按硬件文档接好两板间的绿、黄、黑三根线，再给驱动板独立供电。面板应显示驱动板在线，并收到 M3/M4 编码器数据。主控目前采用电脑 USB 供电。
2. 在英文控制台的 Calibration 页选择轮子与方向、距离标定或转角标定。每一项有独立的保存按钮。总览显示板上已保存的进度，断电后可继续。首次使用先保存方向，再保存距离，之后就能单独标定转角。
3. 距离可用架空转轮采样，两轮各向前转一圈，直径 67.5 mm 时输入 212 mm。转角用地面参考线测量。两项均可先保存参数，随后从各自页面复测并保存。基础遥控使用本车默认方向和每轮独立调速。手机使用 m/s 设定目标，默认 0.40，可选 0.2、0.4、0.6、0.8 快捷档或滑块微调；Acceleration 可选 Smooth 和 Responsive（默认），Actual 按两轮编码器估算车体线速度；ESP32 用编码器反馈在驱动板 ±3600 的 PWM 指令范围内自动调速。直行叠加小幅行程差修正；在 Vehicle telemetry 中可查看左右轮目标、实测速率及已发送 PWM，并下载本次驾驶 CSV。距离复测通过并保存后开放定速和定距，转角复测也通过并保存后开放定角。重新计算距离会保留轮距并要求重新复测距离和转角；单独重标转角保留距离结果。
4. 按住方向键驾驶，松开释放本次驾驶权。独立的“停车”键也可以停止其他连接控制的运动。定距和定角指令均由 ESP32 执行；断线或不再续期后取消动作。
5. 标定后的手动驾驶上限根据两轮距离系数计算，最高 1060 mm/s；车体速度命令 drive_twist 的线速度上限为 100 mm/s，单次定距上限 3 m，转角上限 360°。ESP32 根据标定后的编码器反馈计算轮速并输出限幅 PWM。这些控制参数需要在本车上调试；首次落地前按设计文档完成失联、主控掉电和板间单向断线的架空试验。

## 上位机协议

USB 使用每行一个 JSON 对象（115200、8N1），Wi-Fi 使用 `ws://192.168.4.1/ws`（每条文本消息一个对象）。首先发送：

```json
{"v":1,"id":1,"op":"hello"}
```

后续消息填入应答中的数字 `session`，递增 `id`。发送 `status` 查询状态，或发送 `subscribe`、`topic:"encoders"`、`hz:5` 订阅反馈。`claim` 返回数字 `lease` 和 `window`；在持有期间按 `control_window` 事件更新窗口。手动驾驶以 10 Hz 发送 `drive`。定距与定角只提交一次目标并附 `request_key`，随后发 `heartbeat` 续期。两个入口共用驾驶权，手机和 USB 客户端可同时观察。可选雷达适配器接口位于 [lidar.h](../firmware/controller/src/sensors/lidar.h)，默认配置无雷达。

原先的 [uart_check](../firmware/uart_check) 是独立接线诊断程序，可用于只读查询亚博板参数。
